Guardar como ca.crt la cadena CA confiable correspondiente al hostname de conexión. Para conexión directa descargar la CA del proyecto Supabase. Si se utiliza pooler, comprobar qué CA valida ese endpoint: no asumir que coincide con la conexión directa. Puede requerirse el bundle de autoridades del sistema según certificado del proveedor. No usar certificados inventados ni desactivar verify-full para ocultar errores.
